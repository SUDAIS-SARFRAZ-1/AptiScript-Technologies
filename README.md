# AptiScript Technologies — Corporate Website

AptiScript Technologies is a software development company building modern, scalable, and reliable digital solutions across web development, mobile applications, backend systems, APIs, cloud, and DevOps. **Building Next Generation Software.**

This repo is the company's public marketing/lead-generation website — a Next.js (App Router) + Tailwind CSS site with a contact form as the primary lead-capture flow.

## Project Guidelines

Full project documentation lives in [`.agent/`](.agent/CLAUDE.md) — start there. It links to the PRD, hard rules, stack/architecture instructions, state-management patterns, and UI/UX design spec.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

Other commands:

```bash
npm run build      # production build
npm run lint       # ESLint
```

## Deployment

Deployed on [Vercel](https://vercel.com) — preview deployments per pull request, production deploys from `main`.
